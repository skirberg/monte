# Labels and numbers

> Qualitative data are labels (zip code, team, color). Quantitative data are real amounts (price, height, minutes).

Lesson 5 of 5 in [Data and sampling](https://monte.markets/learn/data.md).

**Question:** Is a zip code a number you can average?

- **No, it's a label** (right answer): Yes. Zip codes name places. An average zip code means nothing.
- Yes, it's made of digits: Digits can be a name. Ask whether doing math on it makes sense.
- Only for one city: Even inside a city, the average of two zip codes is meaningless.

Qualitative data are labels (zip code, team, color). Quantitative data are real amounts (price, height, minutes). Quantitative data are discrete if you count them (bedrooms) and continuous if you measure them (time).

**Question:** Age, recorded in whole years. Discrete or continuous?

- **Continuous** (right answer): Yes. Time flows. Writing it in whole years is rounding, not counting.
- Discrete: Whole numbers can come from rounding something continuous. Age keeps going between birthdays.
- Qualitative: Age is an amount, so it's quantitative.

Decide what kind of data you have first. It decides which summaries and charts make sense.
