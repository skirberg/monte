# The long-run average

> The expected value is each value times its chance, added up: E(X) = Σ x · P(x). It's the long-run average per try.

**Question:** A game pays $10 with chance 0.2 and $0 otherwise. Played many times, what do you win per game on average?

- **$2** (right answer): Yes. 10 × 0.2 + 0 × 0.8 = 2.
- $5: That's the average of 10 and 0 as if they were equally likely. They're not.
- $10: You only win $10 one time in five.

The expected value is each value times its chance, added up: E(X) = Σ x · P(x). It's the long-run average per try.

**Question:** A four-sided die shows 1, 2, 3, 4. What is its expected value?

- 2 or 3: Those are possible rolls. The expected value is the long-run average.
- 4: That's the most you can roll.
- **2.5** (right answer): Yes. Even though you can never roll 2.5. It's an average, not a result.

The expected value doesn't have to be a possible outcome, or the most likely one. It's what you'd average over many tries.
