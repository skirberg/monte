# Going backwards: from a share to a value

> To find a value from a share: find the z that cuts off that share (for example z = 1.96 for the top 2.5%), then value = mean + z × SD.

**Question:** Test scores are normal, mean 70, SD 10. What score puts you in the top 2.5%?

- About 72.5: 2.5% is a share, not points.
- About 80: That's the top 16%, 1 SD up.
- **About 90** (right answer): Yes. Top 2.5% starts about 2 SDs up: 70 + 2 × 10.

To find a value from a share: find the z that cuts off that share (for example z = 1.96 for the top 2.5%), then value = mean + z × SD.

**Question:** Mean 500, SD 40. Roughly what value has 84% below it?

- 580: That's z = 2, about 97.7% below.
- 460: That's z = −1, only 16% below.
- **540** (right answer): Yes. 84% below is about z = 1: 500 + 40.

Share to z, then z to value: mean + z·SD.
