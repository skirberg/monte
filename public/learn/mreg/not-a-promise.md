# Fixed in the math, not the world

> Holding other variables fixed is something the math does. In the world, things move together, and the model can't tell you what happens if you change one.

**Question:** The model says an extra bedroom adds $10k, holding size fixed. Will splitting a room in your house add $10k?

- Yes, but only for big houses: Size isn't the issue. Regression on observational data shows patterns, not causes.
- **Not necessarily** (right answer): Yes. The coefficient compares different houses in the data. It isn't a promise about changing one house.
- Yes, the model says so: Holding size fixed is a comparison across houses, not a guarantee about remodeling.

Holding other variables fixed is something the math does. In the world, things move together, and the model can't tell you what happens if you change one. That needs an experiment.

**Question:** Which claim does a regression on observational data support best?

- Adding a garage will raise your price by $20k: That's a causal claim the data can't back up alone.
- Garages cause higher prices everywhere: The data come from one market and one time.
- **Houses with garages sell for more, comparing similar sizes** (right answer): Yes. A pattern among houses like these.

Regression describes patterns. Cause needs an experiment or a very careful design.
